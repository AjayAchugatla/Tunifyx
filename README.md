# 🎵 Tunifyx - Music Streaming Platform

**Tunifyx** is a music streaming platform. Users can browse and listen to songs, while admins can upload music, manage content, and view analytics.

---

## ✨ Features

### 👤 User Features
- 🎧 Listen to songs seamlessly
- 🔍 Browse by albums, songs
- 📱 Responsive UI for desktop and mobile

### 🛠️ Admin Features
- 🔐 Admin login via **Clerk**
- 📤 Create Albums, upload songs
- 📊 View analytics:
  - Total users
  - Total songs
  - Total albums

---

## 🧰 Tech Stack

| Layer         | Tech                              |
|---------------|-----------------------------------|
| Frontend      | React (TypeScript, Vite)          |
| State Mgmt    | Zustand                           |
| Styling       | Tailwind CSS                      |
| Backend       | Node.js + Express + TypeScript    |
| Database      | MongoDB (via Mongoose)            |
| Auth          | Clerk          |
| Media Upload  | Cloudinary                        |
